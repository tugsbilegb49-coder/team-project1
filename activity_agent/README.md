# АЖЛЫН БҮТЭЭМЖ ШАЛГАХ СИСТЕМ

## 1. Төслийн танилцуулга

Энэхүү төсөл нь ажилтны компьютерийн үйл ажиллагаа болон камерын мэдээлэлд үндэслэн ажлын бүтээмжийг хянах систем юм.

Систем нь ажилтны үйл ажиллагааг цуглуулах, боловсруулах, дүн шинжилгээ хийх болон үр дүнг хадгалах боломжтой.

## 2. Ашигласан технологи

- Python
- OpenCV
- YOLOv8
- Random Forest
- SQLite
- REST API
- Scikit-learn
- Pandas

## 3. Camera модуль

Camera модуль нь OpenCV болон YOLOv8 ашиглан вебкамераас дүрс уншиж, хүн байгаа эсэхийг илрүүлнэ.

Үндсэн ажиллагаа:
- Вебкамераас дүрс авах
- YOLOv8 ашиглан хүн илрүүлэх
- Confidence утгыг тооцох
- Хүн байгаа эсэхийг Boolean утгаар тодорхойлох
- Үр дүнг API руу илгээх боломжтой

**Нууцлал:** Камерын зураг болон бичлэгийг хадгалахгүй. Зөвхөн хүн байгаа эсэх болон confidence утгыг хадгална.

## 4. AI модуль

YOLOv8 нь камерын дүрсээс хүн илрүүлэхэд ашиглагдана.

Random Forest нь туршилтын AI загварын хэсэг бөгөөд одоогийн өгөгдөл хангалтгүй тул найдвартай үр дүн гэж үзэхгүй.

Random Forest-ийн үр дүнг `EXPERIMENTAL` гэж тэмдэглэнэ.

## 5. QA болон туршилтын үр дүн

Камерын хүн илрүүлэх ажиллагааг гараар шошголсон 10 дээжээр урьдчилан шалгасан.

| Үзүүлэлт | Үр дүн |
|---|---:|
| True Positive (TP) | 5 |
| False Positive (FP) | 0 |
| False Negative (FN) | 0 |
| True Negative (TN) | 5 |
| Precision | 1.00 |
| Recall | 1.00 |
| Accuracy | 1.00 |

**Тайлбар:** Эдгээр үзүүлэлт нь зөвхөн 10 дээжийн урьдчилсан туршилтын үр дүн юм. Системийн нийтлэг нарийвчлалыг батлахад илүү олон бодит өгөгдөл шаардлагатай.

## 6. Нууцлал ба зөвшөөрөл

- Камер ашиглахаас өмнө хэрэглэгчийн зөвшөөрөл авна.
- Камерын зураг, бичлэгийг хадгалахгүй.
- Зөвхөн шаардлагатай Boolean үр дүн болон confidence мэдээллийг ашиглана.
- Хэрэглэгчийн мэдээллийг зориулалтын дагуу боловсруулна.

## 7. Тест ажиллуулах

